# 维护策略（MAINTENANCE）

本文明确 AMIG 各版本线的维护范围、迭代节奏与问题处理流程。版本差异见 [VERSIONING.md](VERSIONING.md)，分支规则见 [BRANCHING.md](BRANCHING.md)。

## 1. 维护范围

### 1.2.x（`main`，当前主维护分支）

维护内容：
- 功能迭代与体验优化
- 缺陷修复、安全修复
- 数据库结构演进（`init_db()` 幂等建表 + `schema_migrations` 版本记录）
- 依赖升级、部署与运维工具改进
- 文档同步更新

支持范围：MySQL 8.0 与 8.4 LTS（InnoDB + utf8mb4）。MySQL 5.7 及更低版本、SQLite 运行模式不在支持范围。

### 1.1.x（`1.1.x`，老数据库兼容分支）

维护内容（**仅限**）：
- SQLite 兼容性缺陷修复（如 WAL/锁/事务行为问题）
- 安全漏洞修复（同步 1.2.x 已修复的安全问题）
- 阻断性缺陷的最小化补丁（不引入新功能、不重构）

不维护内容：
- 新功能、UI 改版、性能优化（除非属于阻断性问题的最小修复）
- 数据库架构变更
- 依赖大版本升级

## 2. 迭代节奏

- **1.2.x**：按需发布。安全修复随时以 PATCH 版本发布；功能迭代随 MINOR 版本发布。不承诺固定日历周期，以实际合并内容为准。
- **1.1.x**：不定期。仅在出现兼容性/安全问题且无法通过配置规避时发布补丁，其余时间保持冻结。
- **1.0.x 及更早**：停止维护（EOL），不再接受修复。

## 3. 问题处理流程

1. **登记**：Issue 必须标注版本线标签 `version/1.2.x` 或 `version/1.1.x`；同时影响两条线的，分别登记或在描述中注明"需双线修复"。
2. **定级**：
   - S0 安全/数据丢失：立即处理，1.2.x 优先，1.1.x 同步安全补丁
   - S1 功能阻断：进入当前迭代
   - S2 一般缺陷：排期修复
   - S3 建议：进入待办池，1.1.x 不接受功能类建议
3. **修复落点**：
   - 1.2.x 问题 → `fix/*` 分支 → PR → `main`
   - 1.1.x 问题 → `fix/*` 分支 → PR → `1.1.x`
   - 双线问题：先在 `main` 修复并验证，再按 SQLite 实现单独向 `1.1.x` 提交等价修复；**禁止直接 cherry-pick**（两线数据库实现不同，必须分别验证）。
4. **验证**：1.2.x 的 PR 必须通过全量测试（需可用 MySQL，测试使用随机 `amig_test_*` 库）；1.1.x 的 PR 必须在 SQLite 环境跑对应回归用例。
5. **发布**：见 [BRANCHING.md](BRANCHING.md) 的发布流程；发布必须创建注释标签并记录变更。
6. **回归同步**：安全修复发布后，在另一条线登记对应任务并跟踪闭环；未闭环前不得关闭安全 Issue。

## 4. 发布准入

发布 1.2.x 前必须完成：
- 全量测试通过（`python -m pytest tests -q`）
- `python tools/check_db.py --deep` 在测试库上通过
- 发布包扫描通过（`python tools/build_release.py --scan-only`，不得包含测试/临时/本地配置）
- CHANGELOG 与 README 已更新，版本号（`app/config.py: APP_VERSION`）与标签一致
- `git diff` 已审查，无未提交改动

发布 1.1.x 前必须完成：
- 对应 SQLite 回归用例通过
- CHANGELOG 记录安全/兼容修复内容
- 不包含新功能

## 5. EOL 与归档

- 版本线停止维护后，在 README/CHANGELOG 标注 EOL，并保留其标签与发布记录（不删除历史标签）。
- 1.1.x 进入 EOL 前需提前在 `1.1.x` 分支与 README 中声明"最终版本号"。
- 旧 SQLite 数据迁移工具在 1.2.x 中持续保留，不随 1.1.x EOL 移除。

## 6. 责任分工

| 角色 | 职责 |
|---|---|
| 维护者（Maintainer） | 分支与标签操作、发布准入审核、双线修复闭环跟踪 |
| 开发 | 按落点分支提交、补测试、更新文档 |
| 测试 | 1.2.x 全量回归；1.1.x 兼容回归；发布包内容抽查 |
| 产品/运营 | 版本范围确认、发布说明与用户公告、EOL 通知 |
